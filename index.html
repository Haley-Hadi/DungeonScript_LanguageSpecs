DungeonScript Specification

DungeonScript is a domain-specific language for TTRPG Game Masters. It automates modifier calculations and organizes world-building entities[cite: 3, 6].

Grammar

Defined using Ohm.js, the grammar ensures structural integrity for NPCs and Locations.

NPC = "NPC" string "{" NPCBody "}"
Stat = identifier ":" number

Examples

NPC "Brog" { stats { STR: 18 HP: 45 } }
