DungeonScript Specification

DungeonScript is a domain-specific scripting language designed to streamline TTRPG campaign preparation. It provides Game Masters with a structured way to define world entities that can be exported to Markdown or JSON for use in apps like Obsidian or FoundryVTT.

Core Entity Types

DungeonScript is built around three fundamental building blocks:

  • NPC: Represents characters with attributes, saving throws, and actions.
  • Location: Defines physical settings that can host NPCs and Encounters.
  • Encounter: Represents specific events or combat scenarios.

Stats & Modifiers

One of the core features of DungeonScript is the automatic derivation of ability modifiers. When a GM defines a stat value, the compiler calculates the modifier using the standard TTRPG formula:

Modifier = floor((Value - 10) / 2)

These modifiers can be dynamically referenced in Action damage strings using keywords like STR or DEX.

Language Grammar

DungeonScript uses the Ohm.js parsing library to ensure all files follow a strict, logical structure.

NPC = "NPC" string "{" NPCBody "}"
Location = "Location" string "{" LocationBody "}"
Property = identifier ":" (number | string)
StatBlock = "stats" "{" Stat* "}"
Action = "Action" string "{" ActionBody "}"

Compiler Safety & Defaults

To prevent campaign-breaking errors, the DungeonScript compiler includes several safety "guards":

  • HP Validation: The analyzer throws an error if an NPC is defined with 0 or negative HP.
  • Null Safety: If a stat is missing, the compiler defaults the value to 10 (+0 modifier) to ensure the game remains playable.
  • Proficiency Defaults: NPCs default to a +2 proficiency bonus unless explicitly changed.

Comprehensive Example

This example demonstrates entity nesting and property assignment.

NPC "Brog the Orc" {
  stats {
    STR: 18, DEX: 12, CON: 16, HP: 45, AC: 16
  }
  
  Action "Greataxe" {
    type: "melee", damage: "1d12 + STR"
  }
}

Location "The Rusty Tankard" {
  safety: "Safe"
  environment: "Noisy"
  
  "Brog the Orc" // Nesting the NPC inside the Location
}
